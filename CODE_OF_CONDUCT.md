# Code of conduct

We ask everyone participating in Omenabenz Global Ventures Limited GitHub spaces to communicate respectfully and help keep collaboration constructive.

## Expected behavior

- Discuss ideas and code with care and respect.
- Give useful feedback and accept good-faith corrections.
- Respect different backgrounds, experiences, and viewpoints.
- Protect other people's privacy and confidential information.

Harassment, discrimination, threats, personal attacks, sexual harassment, and publishing private information without permission are unacceptable. Spam and deliberately disruptive behavior are also unacceptable.

## Report a concern

Report conduct concerns privately to [ceo@omenabenzglobalventures.online](mailto:ceo@omenabenzglobalventures.online). Include links or a brief description of the incident and share only the personal information necessary to understand it.

Reports will be handled as privately as practical. Absolute confidentiality cannot be guaranteed where investigation or legal obligations require disclosure.

## Maintainer responsibilities

Maintainers may request changes to content, remove inappropriate material, restrict participation, or block accounts when needed. The response should reflect the nature and severity of the behavior and any relevant history.

This code applies to issues, pull requests, discussions, and other company-managed community spaces associated with these projects.
