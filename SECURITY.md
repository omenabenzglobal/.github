# Security policy

## Report a vulnerability privately

Send suspected vulnerabilities affecting Omenabenz Global Ventures Limited projects or services to [ceo@omenabenzglobalventures.online](mailto:ceo@omenabenzglobalventures.online), with the subject **Security report: [project or service]**.

Include, where available:

- The affected repository, service, URL, and version or commit.
- A description of the issue and its potential impact.
- Minimal steps to reproduce the issue safely.
- Relevant redacted logs or screenshots.
- A contact address for follow-up.

Do not post vulnerability details in public issues or pull requests. Do not send passwords, access tokens, private keys, customer data, or unnecessary personal information. Ask for a suitable secure transfer method before sending sensitive evidence.

Limit investigation to systems and data you are authorized to access. Avoid disrupting services or accessing other users' data.

## Handling and disclosure

Reports will be assessed and follow-up coordinated through the private reporting channel. Please coordinate any public disclosure with the maintainer so that affected users can receive an appropriate fix or mitigation.

This policy does not establish a paid bug bounty or guarantee a response or resolution deadline.

## Supported versions

Supported versions and security-update availability are defined by each project's documentation. No organization-wide version-support schedule is currently published. If the affected project has its own security policy, follow that policy first.
