# Contributing

Thank you for your interest in Omenabenz Global Ventures Limited projects. Check the target repository's README, contribution guidance, development status, and license before starting. Some repositories may not yet accept external contributions.

## Report issues or suggest improvements

Use the relevant repository's issue tracker for reproducible bugs and focused feature suggestions. Describe the expected result, the actual result, and the affected version or commit. Redact logs and screenshots before sharing them.

Report security concerns privately as described in [SECURITY.md](SECURITY.md). For product support or business enquiries, see [SUPPORT.md](SUPPORT.md).

## Submit a change

1. Discuss significant changes in an issue before investing substantial work.
2. Follow the repository's setup instructions and existing conventions.
3. Keep the change focused and explain the problem it solves.
4. Run relevant checks and describe the results in the pull request. State any checks you could not run.
5. Update documentation when behavior or setup changes.

Do not commit credentials, confidential company material, customer data, or unnecessary personal information. Submit only material you have the right to contribute, and follow the project's licensing terms. If a license or contribution policy is unclear, ask the maintainer before submitting code.

Maintainers review contributions as capacity allows; submission does not guarantee acceptance. Please follow our [code of conduct](CODE_OF_CONDUCT.md).
